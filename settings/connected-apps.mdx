---
title: "Connected Apps"
description: "Review and revoke applications that can act on your Scouty account."
---

Open **Connected Apps** in the Dashboard sidebar to review applications authorized to use Scouty on your behalf.

Review the access shown for each connected application. Revoke access when you no longer want it to make requests for your account. Select **Revoke access** for the application you want to disconnect.

Revoking access blocks future requests. It does not undo actions already taken, recall email, or cancel existing meetings. It does not replace the controls for [Auto GTM](/find-prospects/auto-gtm) or the site's [Google Calendar connection](/meetings/google-calendar).

If the page cannot load, use **Try again**. If revocation fails, check the current connection status before assuming access has been removed. Connect the application again through its authorization flow if you later want to use it.
